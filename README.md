# Portafolio — Andrés

Recopilación de trabajos realizados como parte de mis cursos. Cada proyecto vive en su propia carpeta, con su propio detalle técnico.

## Proyectos

### 1. [LogiDrone-UCC](logidrone-ucc)
Aplicación de escritorio (Python + Tkinter) para gestión logística con drones. Implementa estructuras de datos propias desde cero: árbol AVL, lista doblemente enlazada, grafo, cola FIFO, pila LIFO y matriz dispersa, aplicadas a modelos de drones, pedidos y productos.

**Tecnologías:** Python, Tkinter, estructuras de datos personalizadas.

### 2. [inventory-app (StockMate)](inventory-app)
Aplicación web de gestión de inventarios para pequeños comerciantes: registro, actualización y control de stock en tiempo real, con autenticación (incluye Google OAuth) y reportes con gráficos.

**Tecnologías:** Python, Flask, SQLAlchemy, MySQL, Bootstrap, Chart.js.

### 3. [prototipos_interfaces](prototipos-interfaces)
Colección de prototipos de interfaz de usuario (maquetas HTML/CSS/JS) explorando distintos layouts y estilos de navegación para un mismo sitio.

**Tecnologías:** HTML5, CSS3, JavaScript.
